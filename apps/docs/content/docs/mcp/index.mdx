---
title: MCP
description: Scoped agent tools
---

The new local MCP server exposes only:

- `agentis_capabilities`
- `agentis_request_operation`
- `agentis_get_operation`
- `agentis_list_operations`

Provide `AGENTIS_TOKEN` as a scoped executor grant in the server's private environment. `AGENTIS_API_URL` defaults to localhost port 3001. Never give an agent an owner token to bypass approval.

Pending operations return a URL for the human. Retrying the same task must preserve its idempotency key.

Remote MCP is deliberately unavailable during the OAuth rewrite. This working-tree change has not been deployed; do not confuse the old deployed toolset with this implementation.
