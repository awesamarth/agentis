---
title: CLI
description: Request operations and inspect results
---

Build this checkout before using the new CLI. Set `AGENTIS_API_URL` and `AGENTIS_TOKEN` in a private environment. Agents use scoped executor grants, not owner credentials.

```sh
agentis capabilities
agentis operations create --file request.json --key task-1
agentis operations get <id>
agentis operations wait <id>
agentis wallet list --local
agentis wallet create --local --name demo
```

Reuse an idempotency key for retries of the same request. Approval URLs are for the human. Unknown status is not permission to pay again.

Local wallet files use filesystem permissions and standard Ed25519 derivation. Legacy hosted commands and local sends are unavailable until migrated. Use `--help` from this checkout, not the previously published CLI.
