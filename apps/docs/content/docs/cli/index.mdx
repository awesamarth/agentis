---
title: CLI
description: Operate hosted and local agent wallets
---

Install the CLI with Bun, then authorize selected hosted agents and networks in the browser:

```sh
bun add -g @agentis-hq/cli@latest
agentis login
agentis wallet list
agentis wallet balance
```

Hosted commands cover balances, policy/history reads, transfers, paid fetches, Uniswap and ENS. Ask mode returns a dashboard approval URL; automatic mode executes only within the agent's rules.

Local custody supports wallet creation, balances, policies, transfers and x402/MPP paid fetches:

```sh
agentis wallet create --local --name local-agent --chains base,arc,tempo,solana,sepolia
agentis policy show --local --wallet local-agent
```

Local wallet files are plaintext, owner-permission-protected files. Reuse an unchanged request key after uncertainty. An unknown submission is not permission to pay again. Run `agentis --help` for exact flags.
