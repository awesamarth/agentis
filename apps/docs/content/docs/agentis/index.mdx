Agentis connects an agent's financial request to the user's permissions, approval and receipt.

## Rewrite status

This checkout is a foundation preview, not a production release. Base is the product's target default network. Only local Anvil native transfers execute today; live Privy execution and financial plugins are disabled pending verification.

The user owns financial authority. Agents receive wallet-scoped, expiring executor grants and cannot change policy or approve themselves. Every hosted action follows the same backend operation pipeline.

Guest Solana devnet wallets remain available for quick browser tryout. Their keys are stored in localStorage; do not fund those addresses on mainnet.

See the repository's `README.md`, `docs/architecture.md`, and living `AGENTS.md` for setup, evidence and remaining work. Published npm packages and deployments still represent the old prototype.
