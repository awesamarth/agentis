---
title: Agentis
description: Wallets, payments and spending controls for AI agents
---

Agentis gives each agent independent wallets, USD limits, approval rules and optional integrations. Dashboard, SDK, CLI and remote MCP all use the same backend authorization and receipt pipeline.

Hosted wallets use Privy and scoped executor grants. Agents cannot change policy, approve themselves or export hosted keys. Local-custody CLI wallets are also available for users who want keys to remain on their machine.

Choose Base, Ethereum, Tempo, Solana or Arc. Base is selected by default. Turn on **Enable testnets** in agent settings to add Base Sepolia, Ethereum Sepolia, Arc Testnet, Tempo Testnet or Solana Devnet.

See [networks and assets](/docs/agentis/networks) for network keys, supported tokens and amount units.

Mainnet and testnets have separate spending allowances. Direct transfers and x402/MPP paid HTTP requests use the same approval flow. Uniswap and ENS remain available on their supported testnets.

The optional [Agentcard plugin](/docs/agentis/agentcard) connects an owner's card for browser checkout and delegated shopping. It requires explicit per-key card permission and follows the agent's Ask/Auto mode and shared USD budget.

See the repository [README](https://github.com/awesamarth/agentis#readme) for setup and integration examples.
