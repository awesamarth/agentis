---
title: Agentis
description: Wallets, payments and spending controls for AI agents
---

Agentis gives each agent independent wallets, USD limits, approval rules and optional integrations. Dashboard, SDK, CLI and remote MCP all use the same backend authorization and receipt pipeline.

Hosted wallets use Privy and scoped executor grants. Agents cannot change policy, approve themselves or export hosted keys. Local-custody CLI wallets are also available for users who want keys to remain on their machine.

Supported testnets include Base Sepolia, Ethereum Sepolia, Arc, Tempo and Solana Devnet. Agentis supports direct transfers, x402/MPP paid GET requests, Uniswap swaps and ENS identity. Mainnet execution is not enabled.

See the repository [README](https://github.com/awesamarth/agentis#readme) for current setup, supported assets and verification boundaries.
